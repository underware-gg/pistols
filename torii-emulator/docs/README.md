# torii-emulator docs

Top-level entry point for documentation. The split here is semantic and load-bearing.

- **[`shaping/`](./shaping/)** — the process of building: design decisions, implementation plans, research that informs them, and working state. *What we're going to build, why, and how.*
- **[`system/`](./system/)** — the as-built artifact: architecture and reference. *What the system is*, kept in sync with code.

For doc-authoring rules (frontmatter, status values, sync rule, immutability, lifecycle), see [`../AGENTS.md`](../AGENTS.md).
