# plans

How we're going to build it. Append-only.

## Conventions

- One file per work unit. Numbered chronologically (`0001-*.md`). Numbers don't change once assigned.
- Frontmatter: `status` (draft | shaping | implemented | deprecated), `designs:` (numbers).
- Once `status` is `implemented` or `deprecated`, the doc is frozen. If more work is needed, write a new plan.
- Each plan lists the designs it implements. Designs link back. Both ends must agree.
- Each plan lists the system-doc deltas it produces in its `## Implementation docs` acceptance criteria — these land or update when the plan reaches `implemented`.

Use [`TEMPLATE.md`](./TEMPLATE.md) as the starting point for a new plan.
