# Dependency Review: Vitest 4

## Summary

- Date: 2026-08-27
- Scope: move the client and SDK test runner together from Vitest 3.2.6 to
  4.1.11 without changing Vite or application runtime dependencies.
- Classification: moderate-risk tooling major with direct behavioural coverage.

## Candidate Review

`vitest@4.1.11` was published eight days before this review and passes the
repository's seven-day release-age gate. It is not deprecated, has no install
script, and none of its six known advisories affects 4.1.11.

Its required Vite peer range is `^6.0.0 || ^7.0.0 || ^8.0.0`, which includes
the repository's pinned Vite 6.4.3. The current Node policy also satisfies
Vitest's engine requirement. No Vite migration is coupled to this change.

The depth-one candidate review examined these new or moving direct arrivals:

- `obug@2.1.4`
- `std-env@4.2.0`
- `tinyexec@1.3.0`
- `expect-type@1.4.0`
- `tinyrainbow@3.1.1`
- `magic-string@0.30.21`
- `es-module-lexer@2.3.2`
- the lockstep `@vitest/*@4.1.11` packages

Every examined version passes the age and advisory gates and has no install
script. The resolved lockfile diff will be checked for any arrivals that the
depth-one review did not enumerate before the reviewed set is regenerated.

## Compatibility Boundary

Both workspaces use only the stable `vitest` CLI and test APIs. The client has
two test files and a happy-dom setup; the SDK has nine test files, including
happy-dom React hook tests. There is no custom reporter, browser runner,
coverage provider, or Vitest plugin to migrate.

Acceptance requires both focused suites and the complete repository gate to
pass without weakening tests or configuration.

## Commands Run Before Manifest Changes

```sh
pnpm outdated -r --format json
pnpm candidate vitest@4.1.11 --depth 1
```

## Outcome

The controlled resolution produced **1 entered, 9 left, and 17 moved** across
852 resolved package names. The sole entry is the already-reviewed
`obug@2.1.4`. Resolution also exposed two moved versions not enumerated by the
depth-one review, `@standard-schema/spec@1.1.0` and `chai@6.2.2`; both were run
through `pnpm candidate` explicitly and pass the release-age, lifecycle-script,
and advisory checks.

The nine departures are Vitest 3 implementation dependencies, including
`vite-node@3.2.4`, `tinypool@1.1.1`, `tinyspy@4.0.4`, and Chai's former helper
packages. No application-runtime dependency entered the graph.

The reviewed set was regenerated to 1,046 exact `name@version` pairs across
852 packages, and a normal non-bypassed install passed the reviewed-lockfile
gate. Both focused suites pass under Vitest 4: nine SDK files with 39 tests and
two client files with four tests. Full `pnpm verify` also passes, including
dependency policy, audit, lint, both production builds, and both test suites.
No source or test configuration change was required.
